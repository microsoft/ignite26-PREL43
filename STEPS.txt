COWORK LAB - SKILLABLE SET-UP AND TEST STEPS
=============================================
Lab profile: work on a TEST COPY (e.g. PREL 43), not the live one.
All files below are in the  skillable\  folder.

  skillable\HelixKit-1.0.6.iso                       PART A  (upload)
  skillable\lifecycle\Prepare-Helix-Workspace.ps1    PART B  (paste)
  skillable\Lab-Instructions.md                      PART C  (paste)
  skillable\activities\M1 ... M5\*.ps1               PART D  (paste)

How it works in one line: the ISO carries the full hydration kit (scripts + Helix data + portable
PowerShell 7). One small life cycle script inside the lab VM finds the ISO and runs it. The 12
"Check my work" scripts run in Skillable's cloud and read the learner's Microsoft 365.

Nothing needs hosting anywhere. No Azure. No download links.


PART A - REMOVABLE MEDIA (the ISO)                                         ~10 min, once
-----------------------------------------------------------------------------------------
A1. Upload skillable\HelixKit-1.0.6.iso (about 107 MB) to the lab's media storage, e.g.
    SMB2\Microsoft Events\Ignite2026\PREL43-Media\HelixKit-1.0.6.iso
    Check it is the right file (PowerShell):  Get-FileHash .\HelixKit-1.0.6.iso
      515802124A75511815661402BF321396ACBF200B9BD9D5B1FD7AC1A6448D93CD
    NEW ISO RELEASED? Upload it under its NEW name, change the Image Path in A2 to it, and
    re-paste the life cycle script (B3). The script checks the version and stops if the VM
    has a different ISO, so an old copy can never run by mistake.
A2. Edit Lab Profile > Media tab > Add Removable Media:
      Name: HelixKit Media   Media Type: Optical   Image Path: the path above
A3. Save.
A4. Virtual Machines tab > Win11-Pro-Base > DVD Drive:  HelixKit Media.  Save.
    (Adding it under Media only makes it available; DVD Drive inserts it at start.)
    Check: in a launched lab, File Explorer shows a drive labelled HELIXKIT with a
    HelixKit folder.


PART B - LIFE CYCLE ACTION (hydration)                                     ~5 min
-----------------------------------------------------------------------------------------
B1. Edit Lab Profile > Life Cycle tab.
B2. REMOVE any hydration actions added in earlier tests (1-Preflight, 2-TapPolicy, 3-Hydrate,
    4-Readiness, 5-TapIssue cloud scripts).
    TAP actions (Post-Build, "Enable TAP Prereqs + Generate TAP"): leave them as they are.
      Studio does not let us edit them (Invalid action type), and the guide no longer uses a TAP.
    Leave the other disabled actions (License Assignment, GH-Sync, Tear Down) as they are.
B3. Add Life Cycle Action:
      Name:           Prepare Helix workspace
      Action:         Execute Script in Virtual Machine
      Machine:        the Windows lab VM
      Event:          First Displayable   (VM scripts cannot use Post-Build)
      Language:       PowerShell
      Blocking:       TICK it (it is unticked by default)
      Delay:          0
      Timeout:        45 minutes (default 10 is too short)
      Retries:        0
      Error action:   End lab for events. While testing "Log" is fine.
      Enabled:        ticked
      Script:         Start from Scratch > PowerShell > open
                      skillable\lifecycle\Prepare-Helix-Workspace.ps1 in Notepad,
                      Ctrl+A, Ctrl+C, paste.
    What it does: finds the HELIXKIT DVD (waits up to 2 min), starts PowerShell 7, waits for
    internet (up to 5 min), then Grant -> Credits -> Learner -> Preflight -> Hydrate ->
    Readiness -> CreditsCheck. Total about 7-10 minutes on a fresh tenant.
    Grant: if the cloud credential's app (ScoringApp) is missing Graph permissions in this
    launch's tenant, it signs in as that tenant's admin and grants them, then waits until
    they are active (usually 1-5 min). If nothing is missing it does nothing.
    Learner: the learner is this launch's Office 365 admin (Administrative Username).
    If the admin has no licence with Copilot, it gets one: a free seat if there is one,
    otherwise the seat of a spare user (6 users are always kept for the Helix meetings).
    Sets lab variable LearnerUpn; the Check my work scripts use it.
    Credits: switches Cowork on for the tenant. Signs in as the admin and creates a Copilot
    credits spending policy for all users (Cowork on, billed to the tenant's prepaid
    Capacity Pack). This replaces the manual "Activate" in the admin center. It does not
    wait, so the policy switches on while the data is loaded.
    CreditsCheck: at the end, waits (up to 10 min) until the policy is active.
    Line 17 of the script: $RequireCredits = $true  -> a launch without active credits fails
    (End lab). Set it to $false only for a test, then activate credits by hand if needed.
    Uses Microsoft's Copilot Cost Management API, which is a PREVIEW (Graph beta). If it is
    not enabled in the tenant, the log says "not available in this tenant".
B3b. Admin sign-in for Grant and Credits - token names (lines 25-28 of the script):
      $TenantName    = '@lab.CloudCredential(WWLM365E7).TenantName'
      $AdminUser     = '@lab.CloudCredential(WWLM365E7).AdministrativeUsername'
      $AdminPassword = '@lab.CloudCredential(WWLM365E7).AdministrativePassword'
    They are the credential's Lab Access fields "Administrative Username" / "Administrative
    Password" without spaces (like "Tenant Name" -> TenantName, which works). The log prints
    "Tokens filled: TenantName=True, AdministrativeUsername=True, AdministrativePassword=True".
    A False means Skillable did not recognise that name: check the field name in Studio
    (Cloud tab > credential) and change it here. If the username is not filled the script
    uses admin@<this launch's tenant>.
    The admin account must NOT require MFA (the script signs in without a person).
B4. Event date: line 15 of the script reads   $EventDate = 'YYYY-MM-DD'
      - For TESTING leave it: the script uses today.
      - For an EVENT set the event day, e.g.  $EventDate = '2026-11-18'
        and pre-build no earlier than 09:30 the day before (India time).
B5. Save.

The lab VM needs internet access to login.microsoftonline.com and graph.microsoft.com
(normal for this lab; it already opens Microsoft 365 in Edge).


PART C - LAB INSTRUCTIONS                                                  ~3 min
-----------------------------------------------------------------------------------------
C1. Edit Instructions. Ctrl+A, Delete.
C2. Open skillable\Lab-Instructions.md in Notepad, Ctrl+A, Ctrl+C, paste. Save.

What is in it:
  - Getting started starts with a status line: Pre-flight / Hydration / Readiness = ok
    (test build only: delete that NOTE block before the event).
  - Simple English, short steps and bullets.
  - Getting started step 2 opens Copilot and shows the admin Username and Administrative
    Password, and says to set up Microsoft Authenticator if asked (one time). No TAP.
    IMPORTANT: learners sign in with the Office 365 admin, NOT the Azure Portal account.
  - Each milestone ends with "Check your work" and  @lab.Activity(CheckM1) ... (CheckM5).
  - Every prompt is one line and typed with the T icon (copy/paste doesn't reach the VM).
  - Outlook, Teams and OneDrive are opened in Edge, not the desktop apps.

PART E - LAUNCH AND TEST                                                   ~30-45 min
-----------------------------------------------------------------------------------------
E1. Launch a NEW test lab (no pre-build needed for a test). Any change to the life cycle
    action, activities or ISO only applies to labs launched AFTER the change.
E2. Wait: "Prepare Helix workspace" takes about 6-10 minutes. The lab shows as starting.
E3. When the lab opens, Getting started shows:
        Pre-flight: ok   Hydration: ok   Readiness: ok   Copilot credits: ok
    and the sign-in step shows the admin Username and Temporary Access Pass.
    (If the three values are blank but the lab opened, the action still succeeded: lab
    variables may not be settable from VM scripts. Check the life cycle log - see F1.)
E4. In the VM, open Edge > https://m365.cloud.microsoft
    Sign in with the admin Username and Temporary Access Pass (or the password). Set up
    Microsoft Authenticator if asked. Open Copilot and start a Cowork task: it should run
    without asking about credits. Note how long after launch Cowork works.
E5. Check the Helix data is there:
      Outlook: ~35 Helix messages, meetings this week in the calendar
      Teams:   team with the "Launch - Helix" channel, posts and 8 files
E6. All-fail test: go to Milestone 1 > Check your work > Check my work.
    Expected: within ~30 seconds, each item red with its hint,
    EXCEPT "Third focus block not created" which is green (nothing was created yet).
    That is the expected baseline: 10 of 100 points.
E7. Optional pass test: do step 1.3 (three drafts) in Cowork, then Check my work again:
    "Three drafts saved by Cowork" turns green.

OPTIONAL - RUN THE HYDRATION FROM A LAPTOP (fallback only)
-----------------------------------------------------------------------------------------
Needs PowerShell 7 and the tenant's cloud credential (tenant id, client id, secret).
  Open PowerShell 7:  pwsh -ExecutionPolicy Bypass
  cd <this folder>\skillable\media\HelixKit
  $env:HELIXKIT_CLIENT_SECRET = '<client secret>'
  $p = @{ TenantId='<tenant id>'; ClientId='<client id>'; LearnerUpn='<Office 365 Administrative Username>';
          EventDate=(Get-Date -Format yyyy-MM-dd); EventTimeZone='India Standard Time' }
  & .\Preflight.ps1 @p
  & .\Hydrate.ps1 @p
  & .\Readiness.ps1 @p
  & .\Score-All.ps1 @p        # whole scorecard as JSON
  Remove-Item Env:\HELIXKIT_CLIENT_SECRET
